# 05 经费预算与报销单据

> **适用系统**：LTPMS（实验教学项目管理系统）  
> **文档版本**：V2.0  |  **编制日期**：2026-09-21  
> **关联模块**：M4 报表中心 + M1 系统数据管理  
> **说明**：LTPMS 本身不包含财务审批流，本文档定义经费管理的数据口径、预算编制依据、报销单据模板，与系统报表模块对接

---

## 1. 经费管理体系概述

### 1.1 经费分类

| 经费类别 | 说明 | 预算来源 | 关联系统数据 |
|----------|------|----------|-------------|
| 设备购置费 | 实验室设备采购与更新 | 实验室建设专项 | `laboratory.device_count` |
| 耗材费 | 实验耗材日常采购 | 教学运行经费 | 耗材领用记录 |
| 维护维修费 | 设备维修与保养 | 教学运行经费 | 维护记录 |
| 软件授权费 | 教学软件许可采购 | 教学运行经费 | 课程需求 |
| 人员劳务费 | 实验技术人员津贴 | 人员经费 | `user` (role=TEACHER) |
| 差旅培训费 | 教师培训与学术交流 | 师资建设经费 | — |
| 项目经费 | 课题项目研究经费 | 科研/教改项目 | `lab_project` |

### 1.2 经费管理角色

| 角色 | 经费管理职责 |
|------|-------------|
| ADMIN | 全校实验经费预算编制、审批、汇总 |
| 实验室负责人 | 本实验室设备/耗材需求提报、领用审批 |
| TEACHER | 课程实验耗材需求提报、项目经费使用 |

## 2. 预算编制

### 2.1 年度预算编制依据

预算编制应基于以下系统数据：

| 预算项 | 数据来源 | 计算方式 |
|--------|----------|----------|
| 设备购置 | `laboratory` 表设备台数 + 使用年限 | 超过 5 年设备按比例更新 |
| 耗材费 | 上学期耗材领用量 × 单价 | 按课程学生数加权 |
| 维护费 | 历史维修记录 + 设备年龄系数 | 设备数 × 平均维修费率 |
| 软件费 | 课程实验方案中的软件需求 | 按课程逐一核算 |

## 3. 报销单据管理

### 3.1 报销流程

```
经办人填写报销单
    ↓
实验室负责人审核（设备/耗材类）
    ↓
科室负责人审批
    ↓
财务处审核
    ↓
分管领导审批（大额）
    ↓
出纳付款
```

## 4. 经费核算与对账

### 4.1 月度核算

| 核算项 | 数据来源 | 核算口径 |
|--------|----------|----------|
| 设备折旧 | 设备原值 / 使用年限 / 12 | 按月计提 |
| 耗材消耗 | 耗材领用记录 | 按月汇总领用量 × 单价 |
| 维修支出 | 维修费用报销单 | 按月汇总报销金额 |
| 人均实验成本 | 总支出 / 学生总人时数 | 按学期计算 |

| 经费核算项 | LTPMS 报表模块 | 对接方式 |

## 5. 经费审计

### 5.1 审计要点

| 审计项 | 审计标准 | LTPMS 数据佐证 |
|--------|----------|---------------|
| 预算编制合理性 | 预算与实际偏差 ≤ 20% | 历史报表数据对比 |
| 采购合规性 | 单价不超政府采购限额 | 报销单单价字段 |
| 领用真实性 | 领用量与实验学生数匹配 | 人头数报表 |
| 维修必要性 | 故障记录完整、维修合理 | 维护记录 + 故障报告 |
| 经费使用效益 | 人均实验成本合理 | 人时数 / 总经费 |

### 5.2 审计资料清单

| 序号 | 资料名称 | 来源 | 说明 |
|------|----------|------|------|
| 1 | 年度预算表 | 本文档 §2.2 | 预算编制依据 |
| 2 | 月度核算表 | 本文档 §4.1 | 执行进度 |
| 3 | 学期对账表 | 本文档 §4.2 | 预算执行率 |
| 4 | 报销单据汇编 | 本文档 §3.2 | 原始凭证 |
| 5 | 设备台账 | 04_设备与耗材台账 | 设备清单与价值 |
| 6 | 耗材领用记录 | 04_设备与耗材台账 | 领用明细 |
| 7 | LTPMS 报表导出 | 系统导出 Excel/PDF | 人头数、人时数、利用率 |
| 8 | 操作审计日志 | LTPMS operation_log 表 | 关键操作可追溯 |
