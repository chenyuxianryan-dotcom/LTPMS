# 03 人员与权限管理表

> **适用系统**：LTPMS（实验教学项目管理系统）  
> **文档版本**：V2.0  |  **编制日期**：2026-09-21  
> **关联数据库表**：`user` `student` `course_student` `operation_log`  
> **关联模块**：M1 系统数据管理 + M3 学生名单管理 + M8 系统公共

## 1. 角色体系概述

### 1.1 角色枚举

LTPMS 采用三角色体系，存储于 `user.role` 字段（ENUM）：

| 角色标识 | 中文名称 | 登录凭证 | 作用域 |
|----------|----------|----------|--------|
| `ADMIN` | 系统管理员 | 工号（username） | 全站只读 + 系统管理写入 |
| `TEACHER` | 教师 | 工号（username） | 本人所属课程/项目/数据写入 |
| `STUDENT` | 学生 | 学号（username = student_no） | 本人所属项目只读 + 任务提交写入 |

### 1.2 角色数据关联

```
user (id, username, role, ...)
├── TEACHER → teacher 教师档案 (teacher_id = user.id)
│   ├── course (teacher_id) → 排课
│   ├── lab_project (teacher_id) → 课题项目
│   └── schedule (teacher_id) → 课表
├── STUDENT → student 学生档案 (user_id = user.id)
│   ├── lab_project_member (student_id) → 项目成员
│   ├── lab_task_submission (submitter_student_id) → 任务提交
│   └── course_student (student_id) → 课程选课
└── ADMIN → 无额外档案，拥有系统管理权限
```

## 3. 角色创建与管理

### 3.1 管理员（ADMIN）

| 操作 | 方式 | 说明 |
|------|------|------|
| 创建 | 数据库初始化 | 系统初始化脚本创建默认管理员 |
| 权限变更 | 数据库直接修改 | `user.role = 'ADMIN'` |
| 密码重置 | 管理员后台 | 支持批量重置 |

### 3.2 教师（TEACHER）

| 操作 | 方式 | 说明 |
|------|------|------|
| 单个创建 | 管理员后台手动添加 | 工号 + 姓名 + 院系 + 手机号 |
| 批量导入 | Excel 导入 | 模板：工号/姓名/院系/手机号，默认密码 `Ltpms@{工号}` |
| 信息修改 | 管理员后台 | 可修改姓名、院系、手机号 |
| 账号禁用 | 管理员后台 | `user.status` 控制 |
| 密码重置 | 管理员后台 | 重置为默认密码，标记 `is_default_pwd = 1` |

### 3.3 学生（STUDENT）

| 操作 | 方式 | 说明 |
|------|------|------|
| 自动建档 | 名单导入时自动创建 | 遇陌生学号自动创建 `user(role=STUDENT)` + `student` 记录 |
| 手动添加 | 教师在项目内手动输入 | 学号 + 姓名，自动生成账号 |
| 课程名单导入 | Excel 导入课程选课名单 | 模板：学号/姓名/班级/专业 |
| 信息更新 | 重复导入时 upsert | 已有 STUDENT 档案 → 更新班级/专业，不重建账号 |
| 首次登录 | 强制改密 | `is_default_pwd = 1` → 跳转改密页，未改密前不可进入学生页面 |
| 冲突处理 | 学号撞工号拒绝 | 学号已被非 STUDENT 用户占用（工号撞学号）→ 该行拒绝（r2-C2） |

### 3.4 学生档案字段

| 字段 | 数据类型 | 必填 | 说明 |
|------|----------|------|------|
| student_no | VARCHAR(32) | 是 | 学号，全局唯一键，与 user.username 同值 |
| class_name | VARCHAR(64) | 否 | 班级，如"2023级CS2班" |
| major | VARCHAR(128) | 否 | 专业，如"计算机科学与技术" |
| created_at | DATETIME | 自动 | 首次建档时间 |

## 4. 权限控制实现

### 4.1 后端鉴权架构

```
请求 → JWT 拦截器（解析 token → 提取 userId + role）
    → Controller
        → @RequireRole("ADMIN") 注解（角色级校验）
        → Service 层行级校验（authService.requireOwned()）
            → 非本人资源 → 403
        → 写操作审计（AOP → operation_log）
```

### 4.2 关键权限注解

| 注解/方法 | 用途 | 示例 |
|-----------|------|------|
| `@RequireRole("ADMIN")` | 限制仅管理员可访问 | 实验室导入模板下载 |
| `authService.requireOwned()` | 校验资源归属 | 教师只能编辑自己的实验项目 |
| `authService.requireActive()` | 校验资源状态 | 归档项目不可编辑 |
| `authService.isMember()` | 校验项目成员身份 | 学生只能查看所属项目 |
| `SecurityUtils.getCurrentUserId()` | 获取当前用户 ID | 行级数据过滤 |
| `SecurityUtils.getCurrentRole()` | 获取当前用户角色 | 角色级逻辑分支 |

### 4.3 前端权限控制

| 控制层级 | 实现方式 | 说明 |
|----------|----------|------|
| 路由守卫 | `router/index.ts` | 角色 fallback，未登录跳转登录页 |
| 菜单渲染 | 角色条件渲染 | ADMIN 菜单移除实验项目写入入口 |
| 按钮显示 | `v-if="canManage"` | 教师/管理员才显示编辑按钮 |
| 页面可见性 | 路由元信息 | 学生只能访问白名单路由 |

## 5. 人员变更管理

### 5.1 教师岗位变动

| 场景 | 处理方式 | 影响范围 |
|------|----------|----------|
| 教师离职 | 禁用账号 `user.status` | 相关课程、项目、排课数据保留但不可编辑 |
| 教师转岗 | 修改院系信息 | 不影响历史数据归属 |
| 工号变更 | 不支持直接修改 username | 需创建新账号 + 数据迁移 |

### 5.2 学生学籍变动

| 场景 | 处理方式 | 影响范围 |
|------|----------|----------|
| 学生转班 | 重新导入名单，upsert 更新 class_name | `student.class_name` 更新 |
| 学生转专业 | 重新导入名单，upsert 更新 major | `student.major` 更新 |
| 学生退学 | 移出项目成员 | `lab_project_member` 删除，任务状态设为 CLOSED |
| 学号冲突 | 导入时检测并拒绝 | 冲突行记录到导入回执 errors |

### 5.3 权限变更记录

所有权限变更均记录在 `operation_log` 表中：

| 字段 | 说明 |
|------|------|
| user_id | 操作人 ID |
| action | 操作类型（CREATE/UPDATE/DELETE） |
| target_type | 目标实体类型（USER/STUDENT/PROJECT_MEMBER） |
| target_id | 目标实体 ID |
| detail | JSON 格式操作详情 |
| ip | 操作人 IP 地址 |
| created_at | 操作时间 |

## 6. 安全规范

### 6.1 密码策略

| 规则 | 说明 |
|------|------|
| 默认密码 | 教师：`Ltpms@{工号}`，学生：`Ltpms@{学号}` |
| 强制改密 | 首次登录（`is_default_pwd = 1`）强制跳转改密页 |
| 密码存储 | BCrypt 加密存储 |
| 失败锁定 | 连续失败 `failed_attempts` 次后锁定 `locked_until` |
| 改密后标记 | `is_default_pwd = 0` |

### 6.2 数据脱敏规则

| 数据项 | ADMIN 视图 | TEACHER 视图 | STUDENT 视图 |
|--------|-----------|-------------|-------------|
| 学生学号 | 完整显示 | 完整显示 | 仅本人 |
| 学生姓名 | 完整显示 | 完整显示 | 仅本人 |
| 手机号 | 完整显示 | 仅本人 | 仅本人 |
| 操作日志 | 全部 | 仅本人 | — |
| 查询历史 | 全部 | 仅本人 | — |
