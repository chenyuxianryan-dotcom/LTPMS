## 1. 设备台账体系概述

### 1.1 实验室设备管理架构

LTPMS 以「实验室」为核心实体管理教学设备资源，每个实验室对应一栋楼的一间房间：

```
实验室资源体系
├── 实验室基础信息（laboratory 表）
│   ├── lab_code: 实验室编号（如 36-101 = 36 栋 1 楼 01 室）
│   ├── lab_name: 实验室名称（如 基础计算机实验室）
│   ├── manager: 负责人姓名
│   ├── device_count: 设备台数
│   └── status: 状态（启用/停用）
├── 实验室开放计划（lab_open_time 表）
│   ├── 排课时段（学期 + 星期 + 节次 + 周次范围）
│   ├── 面向对象（audience: 全校/指定班级）
│   └── 启用状态
└── 开放异常（lab_open_exception 表）
    ├── 异常时间段（start_date ~ end_date）
    └── 异常原因（reason: 设备维修、场地改造等）
```

### 1.2 设备编号规范

| 编号段 | 含义 | 示例 | 说明 |
|--------|------|------|------|
| 前两位 | 楼栋号 | 36, 37, 38 | 校区内实验楼编号 |
| 第三位 | 楼层号 | 1~5 | 1 楼 ~ 5 楼 |
| 后两位 | 房间号 | 01~02 | 每层 2 间实验室 |

示例：`36-101` = 36 栋 1 楼 01 室，`38-502` = 38 栋 5 楼 02 室

## 3. 设备维护管理

### 3.1 设备状态生命周期

```
正常运行 → 定期维护 → 恢复运行
    ↓           ↓
  故障报修 → 维修中 → 修复验收 → 恢复运行
                ↓
            无法修复 → 报废申请 → 设备下线
```

### 3.2 维护记录表

| 字段 | 说明 | 示例 |
|------|------|------|
| 实验室编号 | 关联 laboratory.lab_code | 36-101 |
| 设备编号 | 序号 + 编号（如 36-101-01） | 36-101-01 |
| 维护类型 | 定期维护 / 故障维修 / 升级改造 | 定期维护 |
| 维护日期 | YYYY-MM-DD | 2026-09-15 |
| 维护人 | 维护人员姓名 | 李建国 |
| 维护内容 | 详细描述 | 更换硬盘、重装系统 |
| 费用 | 维护费用（元） | 350.00 |
| 状态 | 维护中 / 已完成 / 已报废 | 已完成 |

### 3.3 设备检查周期

| 检查类型 | 周期 | 检查内容 | 责任人 |
|----------|------|----------|--------|
| 日常巡检 | 每日 | 设备开关机状态、外设连接 | 实验室值班人员 |
| 周度检查 | 每周 | 软件环境、网络连通性 | 实验室负责人 |
| 月度维护 | 每月 | 硬件除尘、系统更新 | 设备管理员 |
| 学期大检 | 每学期 | 全面检修、设备清点 | 实验室管理科 |

## 4. 实验室开放管理

### 4.1 开放计划（lab_open_time）

| 字段 | 数据类型 | 说明 | 示例 |
|------|----------|------|------|
| lab_code | VARCHAR | 实验室编号 | 36-101 |
| semester_id | BIGINT | 学期 ID | 1 |
| day_of_week | INT | 星期几（1-7） | 3（周三） |
| start_section | INT | 开始节次 | 1 |
| end_section | INT | 结束节次 | 4 |
| week_range | VARCHAR | 周次范围 | 1-16 |
| week_type | VARCHAR | 周类型 | ALL / ODD / EVEN |
| audience | VARCHAR | 面向对象 | 全校 / 2023级CS2班 |
| enabled | BOOLEAN | 启用状态 | true |

### 4.2 开放异常管理（lab_open_exception）

| 场景 | 处理方式 | 影响 |
|------|----------|------|
| 设备故障 | 创建异常记录（起止日期+原因） | 该时段排课冲突检测告警 |
| 场地改造 | 创建异常记录 | 需要调课 |
| 节假日 | 通过 `holiday` 表管理 | 周次计算自动跳过 |
| 临时调课 | 创建异常记录 + 新增排课 | 原排课标记异常 |

### 4.3 实验室利用率计算

**利用率口径**：

```
利用率 = 实际使用人时数 / 可用人时数 × 100%

可用人时数 = Σ(实验室数 × 每实验室设备数 × 每日可用节次 × 教学周数 × 每节次时长)
实际使用人时数 = Σ(排课学生数 × 排课节次数 × 每节次时长)
```

**利用率报表维度**：

| 维度 | 粒度 | 说明 |
|------|------|------|
| 按实验室 | 单个 lab_code | 单实验室利用率 |
| 按楼栋 | 楼栋前缀（36/37/38） | 整栋楼利用率 |
| 按学期 | semester_id | 学期汇总利用率 |
| 按周次 | week_number | 周度利用率趋势 |

## 5. 耗材管理

### 5.1 耗材分类

| 类别 | 示例 | 管理方式 |
|------|------|----------|
| 电子元器件 | 电阻、电容、芯片 | 按实验室领用登记 |
| 实验耗材 | 面包板、导线、焊锡 | 按课程批量采购 |
| 打印耗材 | 纸张、墨盒 | 按月度配额 |
| 网络耗材 | 网线、水晶头、光纤 | 按项目需求领用 |
| 软件授权 | 开发工具许可、云服务 | 按学期采购 |

### 5.2 耗材领用登记表

| 字段 | 说明 | 示例 |
|------|------|------|
| 领用编号 | 自动编号 | HC-2026-001 |
| 实验室编号 | 关联实验室 | 36-101 |
| 领用人 | 教师/学生姓名 | 王伟 |
| 领用日期 | YYYY-MM-DD | 2026-09-15 |
| 耗材名称 | 耗材品名 | 面包板 |
| 规格型号 | 具体规格 | 830 孔 |
| 数量 | 领用数量 | 10 |
| 单位 | 个/米/盒/套 | 个 |
| 用途 | 关联实验项目 | 数据结构综合实践 |
| 审批人 | 实验室负责人 | 张志强 |

### 5.3 耗材库存预警

| 预警级别 | 触发条件 | 处理措施 |
|----------|----------|----------|
| 正常 | 库存 ≥ 安全库存 × 1.5 | 无需处理 |
| 黄色预警 | 安全库存 ≤ 库存 < 安全库存 × 1.5 | 提醒采购 |
| 红色预警 | 库存 < 安全库存 | 紧急采购，暂停领用 |
| 缺货 | 库存 = 0 | 停止领用，立即采购 |
