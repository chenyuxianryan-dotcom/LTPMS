## 2. 测试范围与方法

### 2.1 方法
本系统未采用传统单元测试金字塔，沿用项目既有口径：**功能级验收脚本（HTTP 探针）+ Playwright 真实 UI 驱动**。

- **API 层**：Python 标准库 HTTP 探针，逐断言校验业务码（本项目鉴权失败返回 HTTP 200 + `body.code=403`）、响应结构与副作用。
- **UI 层**：Playwright（headless chromium）+ 真实后端，逐页真实点击；`/settings/notifications`、`/nlq` 等页面此前只有 API 断言或人工实拍，本轮补真实脚本。
- **包含性设计**：涉及写操作的断言一律落在自建临时夹具上并收尾清理；触碰真实数据的场景做前后快照比对；SQL 比对一律带 `deleted=0`。
- **刻意不触发**：迁移确认类端点（`migration/confirm`）、真实「从上学期复制」等爆炸半径大的动作不纳入自动化。

## 3. 关键验证实证

- **管理端全局只读**（01，78 断言）：ADMIN 对实验项目全域读通、写操作全拒，且**写尝试前后真实数据零变更**（快照比对）；跨课程写入被 400 拦截且零搬移。
- **合并改造**（02，23 断言）：SYSTEM 容器并发 ensure 幂等（同容器 id=14）、单课程仅 1 个容器、课程名单全量快照、非归属教师 403；**报表一零改动证明**——`ReportService`/SQL 无 diff，API 输出与直查 SQL 63/63 单元格一致。
- **知识域 ACL**（03）：学生只见本课程资料（课程 10 / doc 6）但可见制度与流程；非任教教师看不到课程 9/10 资料；ADMIN 全量可见；出处字段齐备。
- **图片识别**（04，14 断言）：非图片被魔数拦截；课表图路由 + 识别 3 行 + 课程号命中（NET302/SE201/DB401）；**查询不写回**（T900 课表仍为空）；教师跨归属行被拒；资料页/通知黑板/低置信兜底/人工改道全部符合 PRD。

## 5. 问题清单（4 项，均为测试侧问题）

### P-1 ｜ 测试资产陈旧：b2 UI 套件 T6 段断言视图已改版
- **现象**：`b2_ui_acceptance.cjs` 在 T6 段等待 `/schedules` 的 `.el-table`，超时 15s 后脚本以 exit=2 中止，其后断言未执行。T1~T5 共 **26 项全 PASS**。
- **根因**：批次3（commit `4e0499b`）已把 `/schedules` 默认视图从表格改为**教师书架 + 文件夹动画**，脚本仍按表格视图断言。**非产品缺陷**。
- **影响**：T6 段断言（管理员课表页无「导入课表」/「拍照导入」入口、仍可批量删除；管理员课程页为表格视图、可见授课教师列）**本轮未执行，仍属未验证项**。
- **建议**：把 T6 段改为书架视图断言以恢复覆盖；**并注意该套件 T4 段会真实修改 DB202 课程专业且修订数 +1，属非幂等套件，不宜重复空跑**（本轮已产生「修订 5 → 6」）。

### P-2 ｜ 测试资产陈旧：b3 UI 套件四处硬编码教师人数 20
- **现象**：`b3_ui_acceptance.cjs` 的 A1 / A2 / A5 / F2 断言教师总数为 20，实际 21 → 4 项 FAIL（其余 29 项 PASS）。
- **根因**：2026-09-20 因验收新增了「验收临时教师」账号，教师总数 20 → 21，脚本未同步。**非产品缺陷**。
- **建议**：把三处计数改为「先读接口计数再比对 UI」，消除数据漂移敏感性。

### P-3 ｜ 数据状态漂移：开放管理种子被历史验收演练改写
- **现象**：`outputs/acceptance_open_check.py` 中 36-401 的利用率断言（占用 128h / 19.0%）已失效，现值 **110h / 16.4%**；对应网格周一由「1-8 节有课」变为「1-6 节有课、7-8 开放」。
- **根因**：可完整追溯——`schedule_revision` id=13/14（NET302 周一 5-8 → 5-6，2026-09-16、操作者 TEACHER id=2）与 `schedule` id=22（DB202 行，建于 2026-09-16，即 09-16 验收演练期）。差额 = 128 − 32（NET302 缩减）+ 14（DB202 周五 2-8 周 ×2 节）= 110。**非产品缺陷**。
- **影响**：原套件若直接重跑会误报 FAIL；且该套件 S2 段会真实覆盖 36-401/402 的种子配置，属破坏性脚本。
- **建议**：本轮新增**只读**替代套件（10）按现值断言并加口径自洽校验；如需回到种子态供结题演示，应重跑 `scripts/seed_lab_openings.py` 并同步更新受影响的报表/热力图截图与文档数字——**该动作会改变演示数据，建议由项目负责人决定**。
