## 一句话

阿实从「你问它答的查数员」，升级为「**定时找你 + 有据可查 + 学生也能用**」的助理。能力边界分四圈：本批动圈一（库内事实）与圈三（知识），圈二（从查到算）下批，圈四（系统外）按 多模态 → 联网检索 → 工具执行 逐层开。

## 四把锁的开锁态

### ② 主动性 —— 从「你问」到「它找你」

- **双轨**：晨报（每日 7:30 合并摘要「今天该盯的 N 件事」，周一版给全项目体检）+ 事件预警（提交到达 / 逾期 / 停滞 N 天 / 数据集新版本）
- **渠道只走站内信**，不做企微/邮件；预警默认合并 + 频控 + 可关
- **AI 职责只有排序 + 措辞**：数字一律来自确定性聚合查询，AI 不产生数字
- 底座已验证全通：`SchedulingConfig` 定时 + `NotificationService` 定向推送 + 前端通知面板（60s 轮询未读），几乎零新增基础设施
- 增量位：「订阅式提醒」（确认一次、长期自动）

### ① 知识域 —— 从「查数员」到「有据可查的顾问」

- **一期两类源**：制度与流程（管理员维护）+ 课程与资料（教师自助上传）
- **回答格式**：三源分开摆、**带出处**；通用知识照答，只挂「非课程指定」标签（不再封杀）
- **硬边界**：校内私有库只检索不外传；答不了给「去问谁」出口
- 增量位：历史经验沉淀（往年卡点 / 常见错误，从系统数据长出来）

### ③ 学生侧 —— 从「被挡」到「汇总 + 本人」

- **可见范围**：项目汇总 + 本人明细（沿报表 `aggregate_only` 分层心智，口径一致）
- **入口双开**：悬浮球 + 项目页内嵌
- **首批 5 技能**：`my_briefing`（我的任务简报）/ `task_steps`（任务拆步骤）/ `submit_precheck`（提交前自查）/ `concept_explain`（概念解释，带资料出处）/ `troubleshoot_guide`（苏格拉底式排障：给思路不给答案）
- **红线**：不代写 / 不代做 / 不代交 / 不预测分数；学生侧的「拍」与「算」只给方法步骤、不给结果
- **结构性前提**：服务端注入「你的身份（student id=X）」段 + 硬约束「他人名下行不得进本人清单」（`lab_project_member` 只有 student_id 一列，不做必错）

### ④ 能力范围 —— 四圈地图

| 圈 | 内容 | 本版状态 |
|---|---|---|
| 圈一 库内事实 | 现有查询能力 | 已有 |
| 圈二 库内计算 | 排课·实验室分配 / 延期风险 / 工作量体检 / 备课助手 | **下一批**（壁垒最高、全在系统内、可核对） |
| 圈三 知识 | 锁① 所开 | 本批 |
| 圈四 系统外 | 多模态 → 联网检索 → 工具执行 | 本批开多模态（底座在跑），后两层排队 |

**闸门原则**（圈四放宽的边界）：数据可溯 / 责任可归 / 成本可控。不做代码沙箱。

## 分批

| 批 | 内容 |
|---|---|
| **本批** | ② 主动推送 → ③ 学生侧 → ① 知识库 → ④ 多模态首层（对话支持图片输入） |
| **下批** | 圈二「从查到算」+ 圈四后两层（联网检索 → 工具执行）+ 订阅式提醒 + 历史经验沉淀 |
| **不做** | 企微/邮件渠道；代码沙箱；Agent 直接写库 |

**开工顺序建议**（②→③→①→④）：② 底座全通、见效最快；③ 的身份注入是 ① 对学生可用的前提（早做早解锁）；① 工程量最大（两个管理页 + 检索接入）；④ 换场景不换底座，可殿后并行。

## 落地要件（粗清单，供估工，非详细设计）

- **② 主动**：聚合摘要服务（Java）+ 预警规则与频控 + 前端订阅偏好
- **③ 学生**：`permission.py` 成员注入分支 + 服务端身份段注入 + `NlqWidget` 入口放开 + 5 技能 YAML
- **① 知识**：文档上传管理（教师自助 + 管理员制度）+ 检索接入 agent + 出处标注与「非课程指定」标签
- **④ 多模态**：对话图片输入通道 + 复用 GLM-4V-Flash（课表照片识别已在跑）

## 红线（沿用，不变）

1. Agent 永不直接写库——写意图终止于人工确认点击
2. 权限注入与 SQL 校验只复用不绕过（注入失败 ⇒ 拒绝执行）
3. 数字只来自确定性查询，LLM 只做语言包装
4. ADMIN 全局只读
